# Datový model a invarianty

Úplné typy a runtime schémata jsou v `src/domain/models.ts`; jejich strojová podoba je v `openapi.json`. Každá entita má stabilní id, createdAt, updatedAt, kladnou version a source (`manual`, `import`, `document`). ID není číslo řádku Sheets. `null` znamená neznámý údaj, nikoli nulu. Částky `*Minor` jsou celé haléře / centy. Měna je samostatná a souhrny měny nesčítají. Datum bez času je ISO YYYY-MM-DD; události jsou ISO UTC. Vstup a zobrazení používají Europe/Prague včetně letního času.

OrderStop má vlastní id, typ, místo, časové okno od–do, kontakt a pokyny. V SQL jej lze rozdělit do order_stops; v Sheets ponechat JSON v typovaném sloupci nebo samostatný list s orderId. Stejný postup platí pro oprávnění, položky plánů a vazby karet; mapování musí být jednotné na gateway.

Unikátní omezení: normalizovaná SPZ, neprázdný normalizovaný VIN, číslo CCS karty; jedno individuální service_plan na vehicleId; unikátní (provider, transaction.externalId), importní externalId objednávky a eventId. Dokument deduplikovat podle SHA-256 + typu + vlastníka; CCS opakovaný soubor i s jiným názvem nesmí vytvořit další výpis. Vztahy se nemažou kaskádou. Oprava ekonomiky zachovává audit; přílohy se nekopírují při zobrazení v detailu vozidla.

Stavy jsou explicitní enumy ve schématech. Trip: Probíhá → Ukončena neúplná / K ověření → Potvrzena → Uzavřena. Řidič nepotvrzuje vlastní jízdu. Závada: Nahlášena → Řeší se / Naplánován servis → V servisu → Vyřešena → Uzavřena; oprávněný návrat k řešení je možný, bez schvalování opravy. Stav zakázky není stav jízdy ani dokumentu. Konflikt je dopočtený příznak.

Kanonické náklady: spojené tankování/CCS používá částku CCS, po řešení resolvedMinor. Nevyřešené podklady jsou předběžné a mimo doložený součet. Pokud existuje nespárovaný CCS kandidát stejné karty/data/vozidla, účtenka se nepřičte podruhé ani do předběžného součtu; nejde o automatické přiřazení. Bez CCS karty tvoří ruční tankování samostatný náklad. Výdaje jsou včetně deklarované DPH, cena přepravy bez DPH. Odhady servisu se nesčítají. Spotřeba zahrnuje dílčí tankování mezi dvěma plnými s doloženými nájezdy.
